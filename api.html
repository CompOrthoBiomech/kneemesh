kneemesh.vol.smooth_isocontour(mesh, iterations=50, pass_band=0.001)[source]¶

Smooth a surface mesh with a windowed sinc filter, keeping its connectivity.

Boundary smoothing is off, so any open edges stay in place, and non-manifold smoothing is on. Coordinates are normalized to the unit cube while filtering, so the result does not depend on the physical scale.

Parameters:

  • mesh (vtkPolyData) – Surface from extract_isocontour.

  • iterations (int) – Number of filter iterations, which is the degree of the filter’s polynomial. More iterations follow the pass band more closely. 0 returns the mesh unchanged.

  • pass_band (float) – Pass band of the filter, between 0 and 2. Lower values smooth more and shrink the surface more.

Returns:

A new smoothed mesh, or mesh itself when iterations is 0.

Raises:

ValueError – If iterations is negative or pass_band is not in (0, 2].

kneemesh.segmentation.assemble_label_maps(label_maps, interpolator='label_gaussian', padding=4)[source]¶

Resample single-label LabelMaps onto one grid and combine them into a multilabel Segmentation.

Every nonzero voxel of an input belongs to its structure. The shared grid takes the first input’s direction cosines, the smallest voxel spacing of any input along each axis, and the bounding box of all inputs in physical space, padded with background on every side. Input axes count toward the shared axis nearest them in direction, and the grid’s voxel faces line up with the input that has the smallest spacing along each axis. Structures get label values 1, 2, … in the order given. Where resampled structures overlap, the one given later wins.

Parameters:

  • label_maps (Mapping[str, Image]) – Single-label 3D LabelMaps by structure name.

  • interpolator (Interpolator) – “label_gaussian” resamples with sitkLabelGaussian, which smooths the voxel staircase on finer grids. “nearest_neighbor” uses sitkNearestNeighbor.

  • padding (int) – Background voxels added beyond the bounding box on each side.

Returns:

The assembled segmentation, sitkUInt8 for up to 255 structures and sitkUInt16 above that.

Raises:

ValueError – If label_maps is empty, an input is not a 3D LabelMap of an accepted pixel type or has no foreground, interpolator is unknown, padding is negative, or a structure vanishes in resampling or is entirely covered by later ones.

Return type:

Segmentation

B-rep values, gmsh sessions, and B-spline construction shared by every structure.

Return type:

Mesh

Node optimization of hexahedral meshes for the scaled Jacobian.

Two strategies run in turn on the hexahedra’s corner nodes:

  1. Smart Laplacian smoothing moves each node toward the average of its edge neighbors, keeping a move only if it does not lower the worst scaled Jacobian of the elements around the node.

  2. Optimization minimizes the sum of 1 / SJ over every element corner by projected gradient descent. The objective grows without bound as a corner degenerates, so no step can invert an element, and it weighs the worst corners most.

Boundary nodes are classified from the mesh’s own boundary quadrilaterals. Where adjacent boundary faces meet at more than a feature angle, their shared edges are feature edges. Surface nodes slide in their tangent plane and may leave it by a fraction of the local element size; nodes on a feature edge slide along it with the same allowance off it; feature corners stay fixed. By default the surface nodes’ net offset off their tangent planes is removed, which keeps the mesh’s volume. Tangential travel is also limited, so the tangent plane stays a good model of the surface. High-order nodes follow the corners of their element.

kneemesh.mesh_optimization.optimize_hexahedral_mesh(mesh, laplacian_iterations=10, optimization_iterations=200, surface_deviation=0.1, surface_travel=0.5, feature_angle=30.0, preserve_volume=True)[source]¶

Move a hexahedral mesh’s nodes to raise its scaled Jacobians, keeping connectivity.

Smart Laplacian smoothing runs first, then optimization of the sum of 1 / SJ over every element corner. Optimization needs every element valid, so it is skipped with a warning if smoothing leaves one inverted.

Boundary allowances scale with each node’s local size, the mean length of the element edges at the node. Feature edges are boundary edges where the faces on either side meet at more than feature_angle; nodes where feature edges end, branch, or turn by more than feature_angle are fixed.

Parameters:

  • mesh (Mesh) – Mesh of linear or high-order hexahedra, such as hexahedral_mesh returns.

  • laplacian_iterations (int) – Smart Laplacian sweeps. 0 skips smoothing.

  • optimization_iterations (int) – Gradient steps of the optimization. 0 skips it.

  • surface_deviation (float) – How far a boundary node may move off its starting tangent plane, or off its feature edge, as a fraction of its local size. 0 keeps boundary nodes on their tangent planes and edge lines.

  • surface_travel (float) – How far a boundary node may slide along its tangent plane or feature edge, as a fraction of its local size.

  • feature_angle (float) – Angle in degrees between boundary face normals above which their shared edge is a feature edge.

  • preserve_volume (bool) – Remove the area-weighted mean of the surface nodes’ offsets off their tangent planes, so they can move out in some places and in at others but not swell or shrink the mesh overall. Without it, optimization tends to push the whole surface outward, adding about 5% to a meniscus at surface_deviation 0.1.

Returns:

A new Mesh with the same connectivity and moved nodes. High-order nodes move with the trilinear interpolation of their element’s corner displacements, so curved edges keep their offsets from straight ones.

Raises:

ValueError – If the mesh has elements other than hexahedra or an argument is out of range.

Return type:

Mesh

kneemesh.pipeline.configure(config_type, description, argv=None, timestamp=None)[source]¶

Build a configuration from command-line options, an optional JSON file, and overrides.

Every field of the configuration is an option, such as –points-per-slice for points_per_slice. A field holding another configuration, a section such as meniscus, gives an option for each of its fields, such as –meniscus.points-per-slice. Values given on the command line override those in –config, field by field within sections. The configuration is saved so the run can be repeated: as settings<timestamp>.json in the working directory when there is no –config, or as <config stem>_modified.json beside the file when overrides change it. A config file used without overrides is not copied.

Parameters:

  • config_type (type[ConfigType]) – Configuration model of the command.

  • description (str) – Description for the command’s help.

  • argv (Sequence[str] | None) – Command-line arguments, by default sys.argv[1:].

  • timestamp (str | None) – Timestamp for the settings file name, by default the current time.

Returns:

The configuration, the –config file if any, and the path the configuration was saved to, or None if it was not saved.

kneemesh.geo.meniscus.centerline(label_map, label=1)[source]¶

Fit a smooth curve through the centers of a label’s cross-sections.

BinaryThinning only thins in 2D, so the label is projected along the image axis closest to its thinnest direction and the longest path through that skeleton gives a first estimate of the curve. The curve is then repeatedly moved onto the centroids of the label’s cross-sections normal to it.

Parameters:

  • label_map (Image) – 3D LabelMap of sitkUInt8, sitkUInt16, or sitkInt16 pixels.

  • label (int) – Value of the structure to fit.

Returns:

A cubic B-spline over u in [0, 1]. Evaluating it at N parameters gives an (N, 3) array of physical points. Which end of the structure is u = 0 is unspecified.

Raises:

ValueError – If the image is not a 3D LabelMap of an accepted pixel type, or the label is absent or too small to fit.

Return type:

BSpline

kneemesh.geo.meniscus.slice_isocontour(mesh, curve, spacing, points_per_slice=32)[source]¶

Slice a mesh with planes normal to a curve at uniform arc-length spacing.

Slices are spaced exactly spacing apart along the curve, with any remainder split equally between its two ends, and are ordered along the curve from u = 0. Each cut is resampled to evenly spaced ordered points with a closed Kochanek spline. Slices are removed from either end of the curve until one encloses at least 20% of the average area.

In-plane axes are defined from the curve’s best-fit plane, so they do not twist along a roughly planar curve.

Parameters:

  • mesh (vtkPolyData) – Closed surface from extract_isocontour or smooth_isocontour.

  • curve (BSpline) – Curve from centerline.

  • spacing (float) – Arc-length distance between slices, in physical units.

  • points_per_slice (int) – Number of points on each contour.

Returns:

The retained ContourSlices.

Raises:

ValueError – If spacing is not positive, points_per_slice is below 3, or a retained plane does not cut the mesh in a closed contour.

Return type:

list[ContourSlice]

kneemesh.geo.meniscus.contours_to_brep(slices, spline_order=3, cap='none', cap_offset=None)[source]¶

Loft a B-spline surface through contour slices, optionally capping its ends.

Each contour becomes a periodic B-spline through all of its points, at parameters shared by every contour, and the surface interpolates those curves in the order given, at parameters proportional to the distance between slice centers. Without caps it spans only the first to last slice.

Parameters:

  • slices (list[ContourSlice]) – Contours from slice_isocontour, in order along the curve.

  • spline_order (int) – Polynomial degree of the contour splines. The degree along the curve is at most 3. 3 is cubic, and 1 gives a ruled surface.

  • cap (Literal['none', 'planar', 'smooth']) – How to close the two ends. “none” leaves an open surface. “planar” closes each end with a flat face in its slice’s plane. “smooth” closes each with a convex dome converging to one point. Either cap produces a closed solid.

  • cap_offset (float | None) – For smooth caps, how far each apex lies beyond its slice’s center along the curve, in physical units. By default, a quarter of the radius of a circle with the end slice’s area.

Returns:

The lofted shape.

Raises:

ValueError – If there are fewer than 2 slices, spline_order is outside 1 to 25, a contour has too few points for spline_order, contours have unequal point counts, cap is unknown, or cap_offset is not positive.

Return type:

BRep

kneemesh.geo.meniscus.contours_to_hex_blocks(slices, spline_order=3)[source]¶

Build a planar-capped solid from contour slices as five blocks for hexahedral meshing.

The section is split with a butterfly (O-grid) partition: an inner quadrilateral surrounded by four blocks, one for each of four arcs of the boundary. Every boundary point meets a spoke running inward, so the cells along the boundary stay close to square even at its sharp corners. A partition that puts block corners at those corners instead gives cells there the corner’s angle, or nearly 180 degrees where smoothing rounds it.

The four split points divide each contour into arcs of equal length, rotated to keep them as far as possible from the sharpest turns averaged over all slices. Straight spokes run from each split point to a corner of the inner quadrilateral, partway toward the section’s centroid.

The blocks’ faces are B-spline surfaces interpolating the slices with a knot vector shared by every face along the curve, so neighboring faces meet exactly. contours_to_brep builds its surface the same way, but at shared contour parameters rather than split at the block corners, so the two differ slightly.

Parameters:

  • slices (list[ContourSlice]) – Contours from slice_isocontour, in order along the curve, all with the same number of points.

  • spline_order (int) – Polynomial degree of the section curves. The degree along the curve is at most 3.

Returns:

A solid of five blocks, for hexahedral_mesh.

Raises:

ValueError – If there are fewer than 2 slices, spline_order is outside 1 to 25, a contour has too few points for spline_order or fewer than 8, or contours have unequal point counts.

Return type:

BRep

Hexahedral meshing of the meniscus’s five-block butterfly solid.

kneemesh.mesh.meniscus.hexahedral_mesh(brep, elements_per_edge=4, elements_along=20, element_order=1, second_order_incomplete=False)[source]¶

Mesh a solid of six-sided blocks with hexahedra, using transfinite surfaces and volumes.

Every block must have six faces, such as the five blocks from contours_to_hex_blocks. Edges on the planar end caps get elements_per_edge elements, and the edges running between the caps get elements_along, so each block is a grid of elements_per_edge by elements_per_edge quadrilaterals swept elements_along times.

Parameters:

  • brep (BRep) – A solid of six-sided blocks with planar caps.

  • elements_per_edge (int) – Elements along each edge of a cap.

  • elements_along (int) – Elements along the solid between the caps.

  • element_order (int) – Polynomial order of the elements. 2 gives 27-node hexahedra.

  • second_order_incomplete (bool) – Omit face and interior nodes from high-order elements, giving 20-node instead of 27-node second-order hexahedra.

Returns:

The hexahedral mesh.

Raises:

ValueError – If a count is below 1, or brep is not a solid of six-sided blocks with planar caps.

Return type:

Mesh
